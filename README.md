# IRC-RSS-Bot
An IRC bot posting news and links from RSS feeds into a channel
IRC News BotThis is a Python-based IRC bot that connects to an IRC server, joins a channel, and posts news from various Linux-related RSS feeds.FeaturesIRC Connectivity: Connects to a specified IRC server and channel.RSS Feed Fetching: Fetches news from multiple RSS feeds.Scheduled Posting: Posts news updates to the IRC channel at a specified interval.Random Intros: Adds a random introductory phrase to each news post.Duplicate Post Prevention: Avoids posting the same news item twice.RequirementsPython 3.xirc.py library: pip install ircfeedparser library: pip install feedparserschedule library: pip install scheduleSetupInstall Dependencies:pip install irc feedparser schedule
Configuration:Set the following variables in the your_bot_script.py script:IRC_SERVER: The IRC server address (e.g., "irc.oftc.net").IRC_PORT: The IRC server port (e.g., 6667).CHANNEL: The IRC channel to join (e.g., "#debian-social").NICKNAME: The bot's nickname (e.g., "NewsMan").POST_INTERVAL_MINUTES: The interval in minutes between news posts (e.g., 120).rss_feeds: A dictionary of RSS feeds to fetch news from.  You can modify this dictionary to add or remove feeds.intros: A list of introductory phrases used when posting news. You can modify this list to change the bot's intro messages.Run the Bot:python your_bot_script.py
UsageOnce the bot is running, it will connect to the specified IRC server and channel. It will then fetch news from the configured RSS feeds and post them to the channel at the specified interval.Code Overviewfetch_and_post_news(connection): Fetches news from a random RSS feed, checks for new entries, and posts the title and link to the IRC channel.start_scheduler(connection): Starts a scheduler that calls fetch_and_post_news() at the configured interval.  It uses a separate thread to run the scheduler.on_connect(connection, event): Callback function that is called when the bot connects to the IRC server.  It joins the channel, fetches the initial news and starts the scheduler.main():  Connects to the IRC server and sets up the event handler for the welcome event.Add/Remove RSS FeedsTo add or remove RSS feeds, modify the rss_feeds dictionary in the script.  The dictionary keys are the names of the feeds, and the values are the corresponding RSS URLs.Customize Intro MessagesTo customize the introductory messages, modify the intros list in the script.  You can add, remove, or change the phrases in this list.Important NotesEnsure that the bot has the necessary permissions to join and post messages in the IRC channel.The bot is designed to run continuously and post news updates automatically.The seen_entries set is used to prevent the bot from posting the same news item multiple times.
